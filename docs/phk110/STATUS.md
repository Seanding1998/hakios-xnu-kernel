## 项目简介与目标

**简介**：把 **HakiOS**（开源项目 github.com/oosexgang：让 Apple 的 XNU 内核直接跑在安卓高通手机上）移植到**一加 Ace 2（PHK110 / 骁龙 8+ Gen 1 / 16GB）**。上游的参考设备是 POCO X5 Pro；社区在 SM8475 上已有 K60（mondrian）、MIX Fold 2、POCO F5 Pro 等同 SoC 先例，本分支将上游扩展到 PHK110。所有改动只落在备用启动槽 `boot_b`（日常安卓在 `boot_a`，从不刷写），实验失败由 bootloader 自带的 A/B 回退退回安卓，做成**非破坏性的双系统研究平台**。

**总目标（v1.0）**：功能状态等效上游参考设备——显示/触摸/按键/8 核/GPU(OpenGL ES)/Wi-Fi/存储(/var 持久化)/音频/电池/振动/热管理可用，蜂窝半通。**近期目标 v0.1（黑盒启动链）已达成**（Boot #12）：UEFI + 加载链 + XNU 内核在真机持续运行、日志可取证。**远期方向**：Windows + 安卓 + iOS 三系统共存（同一 UEFI 底座）。**明确不做**：替代日常系统、刷写 boot_a、Apple 服务；IPSW 使用者自备。

**方法**：每个阶段独立成篇，结论以真机实测为准。

## 现状（2026-11-10）

按时间线走，到今天为止项目的样子：

- **10-31 ~ 11-03，让内核跑起来**：UEFI 底座（udonPkg）重建 → payload 嫁接 → 平台表 → 内核日志落盘 → 修中断控制器（GIC 地址与重分配器步进两处）→ **Boot #12 内核跑进用户态**（Darwin 横幅 + "Hello from user space"）→ **Boot #13 内核常驻 60 秒、8 核全上线**。
- **11-03，触摸与按键**：新写 S3910 触摸驱动（GENI SPI，端口固件禁了 FIFO，读方向 bitbang），三轮后探针通过（部件号 "S3910PA0B0-15.2"，面板 1240×2772）；按键经 SPMI v7 仲裁器，三键事件带毫秒时戳。中途一轮把问题误诊为"芯片电气故障"，靠原始字节取证推翻。**v0.3 四项（常驻/8 核/按键/触摸探针）全部达成**（Boot #14–#21）。

- **11-08，用户态与身份链**：`hw.target` 查询失败的根因（loader 占位身份 → 设备树无 `model` → EINVAL）定位并双层修复；**launchd 带起 28 个进程，sshd 监听 :22**（Boot #25）。
- **11-08 ~ 11-10，USB 服务通道与 SSH**：经七个小阶段，把 vendor USB 驱动的复位流程缺陷（CORESOFTRESET 超时后不复位）和主机侧的可见性/管道问题逐一清掉；**2026-11-10 晨 SSH 验证通过**——三条独立会话、root shell、256 KiB 校验传输、干净退出后 loader 存活（判定文件 `verdict27-20261110-060630.txt`，镜像 v23 graft `9e0609fb…`）。
- **当前（进行中）**：`/var` 持久化的长程复验（阶段 28 已建回归门）；GPU/WindowServer（v0.5 路线）与 WiFi（ath11k 工具已备）未开始。
